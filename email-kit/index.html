Install your signature — Gmail

  1. Open the signature. Click inside the white box, select all of it (Cmd + A may grab the page, so click-drag across the signature instead), and copy (Cmd + C).
  2. In Gmail: Settings (gear, top right) → See all settings → General tab.
  3. Scroll to Signature → Create new → name it "Meraki" → paste into the box (Cmd + V).
  4. Under "Signature defaults," set it for new emails and replies.
  5. Scroll down and click Save Changes.

Install your signature — Bluehost webmail

  1. Log in to your Bluehost webmail (Roundcube).
  2. Settings → Identities → click your email address.
  3. Turn on HTML signature (the toggle near the signature box), paste the signature, and Save.

Save the templates in Gmail

  1. One-time setup: Gmail Settings → See all settings → Advanced → set Templates to Enable → Save Changes.
  2. Open a template, select everything in the white box, and copy it.
  3. Click Compose, paste into the email body.
  4. Click the three dots (bottom right of the compose window) → Templates → Save draft as template → Save as new template → name it.
  5. Repeat for each template (do this once).
  6. To use one later: Compose → three dots → Templates → pick it → fill in anything in [brackets] → send.
Before you send: every template has spots in [brackets], like [Name] and [project]. Replace those with the real details each time. The signature is already filled in.
